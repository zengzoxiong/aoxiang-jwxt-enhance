# 翱翔教务功能加强

西北工业大学教务系统（jwxt.nwpu.edu.cn）增强用户脚本，需配合 Tampermonkey 使用。

## 功能

1. GPA 综合分析报告
2. 导出课程成绩与教学班排名
3. 学生画像显示增强
4. 选课助手
5. 课程关注与后台同步
6. 一键自动评教
7. 人员信息检索

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 [aoxiang-jwxt-enhance.user.js](aoxiang-jwxt-enhance.user.js) 点击安装

## 更新

脚本通过 GitHub 仓库维护，可点击悬浮球菜单「检查版本更新」获取最新版本。
