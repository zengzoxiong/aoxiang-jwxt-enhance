# 翱翔教务功能加强

> 西北工业大学翱翔教务 / 翱翔门户增强用户脚本，需配合 [Tampermonkey](https://www.tampermonkey.net/) 使用。

一个面向西工大学生的教务系统增强脚本，围绕**成绩分析、选课辅助、评教自动化、常用入口聚合**四大场景，把原本分散、需要多步点击的教务操作整合到一个悬浮球菜单里，帮助你更快查成绩、更稳抢课、更省事地完成评教。

脚本以「无侵入、按需增强」为原则运行：不改动教务系统本身的数据，仅在页面之上叠加分析、同步、导出与提醒等功能，所有数据均保存在本地浏览器中。

## 适用站点

| 站点 | 域名 | 主要功能 |
| --- | --- | --- |
| 翱翔教务 | `jwxt.nwpu.edu.cn` | 成绩分析、选课助手、数据存档、评教、培养方案、课表教材等 |
| 翱翔门户 | `ecampus.nwpu.edu.cn` | 人员信息检索、常用链接访问、版本更新 |

| 研究生教育 | `yjsjy.nwpu.edu.cn` | 相关页面增强 |

## 功能特性

### 成绩与学业分析

- **GPA 综合分析报告**：一键查看加权均分（标准算法 / 百分制）、专业排名、卡绩分析，并内置 **GPA 计算器**，可预估不同成绩对绩点的影响。
- **导出成绩与教学班排名**：生成包含**教学班排名**的 Excel 成绩单，方便留档与对比（基于 ExcelJS）。
- **学生画像增强**：进入「学生画像」页面时，自动在顶部新增加权平均分卡片，并优化底部「计划外课程」表格的显示效果。

### 选课助手与数据存档

- **选课数据同步面板**：点击「同步最新选课数据」进入功能弹窗，支持
  - **在线同步**：从教务系统抓取最新选课学期的课程与名额数据；
  - **数据导出**：将已同步的数据导出，便于备份或分享给他人；
  - **本地上传**：导入他人分享的选课数据，即使忘记提前缓存也能补上参考数据。
- **三槽位存档系统**：提供 3 个固定存档位，同步结果写入「使用中」的存档，可防止误操作覆盖、支持回溯过往数据；可任选一个存档作为选课助手的数据源，并支持重命名、删除与手动管理。
- **课程关注（收藏）**：在「全校开课查询」「培养方案」页面点击课程旁的收藏按钮即可关注课程；在「课程关注列表」中可切换**课表视图**，直观查看已关注课程的时间冲突情况。
- **选课页增强**：
  - 意愿值选课：显示存档中的「历史余量 / 上限」参考数据；
  - 直选选课：自动显示「待释放名额」；
  - 已关注课程背景高亮，便于快速定位。
- **培养方案课程代码智能预览**：培养方案页的课程代码自动高亮，并展示最新学期的教学班信息。
- **选课时间提醒**：以日程表形式展示各轮选课的时间、方式与范围，并在开选前提前提示同步数据。
- **后台静默数据同步**：在后台自动维护课程数据缓存，减少手动操作。

### 实用工具

- **一键自动评教**：进入评教页面后一键打开自动评教面板，支持**任意给分**与**指定给分**两种模式。
- **人员信息检索**：在门户 / 教师页面按姓名等信息检索人员，并支持跨标签页自动注入搜索。
- **我的课表教材信息显示**：在「我的课表」中展示课程教材信息，并提供学堂在线、中国大学 MOOC、超星、智慧树等网课平台的快捷跳转。
- **常用链接访问**：聚合友情链接、校内网站与网课平台的一键入口（详见下方「常用链接」）。

### 体验优化

- **加载速度优化**：拦截页面中的异常图片请求，加快网页加载。
- **统一 UI 与弹窗**：全部界面图标采用 SVG（无 emoji），弹窗、悬浮球、面板风格统一。
- **悬浮球入口**：所有功能集中在可拖拽的悬浮球菜单中，随叫随到。
- **版本更新检查**：菜单内「检查版本更新」可获取并提示最新版本。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 打开 [aoxiang-jwxt-enhance.user.js](aoxiang-jwxt-enhance.user.js)，按提示点击安装即可。

## 快速上手

1. 登录教务系统，页面右下角会出现**悬浮球**；
2. 查成绩 / 排名：悬浮球 →「GPA综合分析」或「导出成绩与排名」；
3. 抢课准备：进入「全校开课查询」页 →「同步最新选课数据」抓取并存档 → 收藏关注的课程 → 到选课页查看历史余量与待释放名额；
4. 完成评教：进入评教页面 →「一键自动评教」；
5. 需要帮助时：悬浮球 →「脚本使用说明」查看内置图文指引。

## 更新

脚本通过仓库维护，可点击悬浮球菜单中的「检查版本更新」获取最新版本；也支持通过脚本头部的 `updateURL` 自动更新。

## 运行环境与依赖

- **运行环境**：现代浏览器 + Tampermonkey（或兼容的油猴管理器）
- **当前版本**：1.8.3
- **外部库**：[ExcelJS](https://github.com/exceljs/exceljs) 4.3.0、[FileSaver.js](https://github.com/eligrey/FileSaver.js) 2.0.5
- **脚本权限**：`GM_xmlhttpRequest`、`GM_setValue` / `GM_getValue`、`GM_registerMenuCommand`、`unsafeWindow`
